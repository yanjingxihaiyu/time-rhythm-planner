# time-rhythm-planner

一个 WorkBuddy **用户级 skill**：基于已验证的周精力节律，生成本地周/日计划草稿，并可同步进本地「创作者工作台」，按时做复盘沉淀到知识库。

> 本仓库是「方法模板版」，已脱敏——所有私人日程（家庭分工、健康约束、训练/课程名、年度目标等）均用 `[占位符]` 表示，可直接套用自己的节律。

## 适用触发
当用户说「帮我排这周 / 做个作息表 / 周计划 / 日计划 / 精力怎么排 / 把训练排进日程」时触发。

## 装到 WorkBuddy
把本仓库克隆到用户级 skills 目录，WorkBuddy 会自动识别 `SKILL.md`：

```bash
git clone <本仓库地址> ~/.workbuddy/skills/time-rhythm-planner
```

## 包含什么
- **周节律锚（模板）**：晨间流程、训练日、执行日、服务日、家庭日、灵感补给——以结构化占位模板给出，替换成你自己的节律即可
- **短视频 8 步流水线**：选题 → 脚本 → 服装 → 拍摄 → 剪辑 → 发布 → 数据反馈 → 复盘
- **创作灵感两步**：① 向外获取（采集收件箱）/ ② 内省总结（私人，AI 不代写）
- **年 → 季 → 月 → 周 → 日 五层规划映射**：对应本地创作者工作台的数据域
- **工作台启动方式**：桌面图标、固定访问地址、服务掉线如何重起（端口/密钥以你本机为准）
- **每周自动复盘链路（可选）**：读工作台 JSON → 生成结构化周复盘 → 沉淀进你的知识库

## 数据域 ↔ 模块映射（创作者工作台）
| 域 | 装什么 |
|---|---|
| `plans` | 周节律骨架 + 本周重点（按周映射，每周一自动翻篇） |
| `series` | 短视频 N 条内容线 / 选题库 |
| `ideas` | 创作灵感补给（采集收件箱，非沉淀库） |
| `tasks` | 今日必做 + 当日时间表（按上午/下午/晚上） |
| `planning` | 年度目标 → 季度重心 → 每月工作重点 |
| `reviews` | 发布后数据反馈复盘 |

## 注意
- 本 skill 默认锚是一份**示例模板**，首次使用前请把 `SKILL.md` 二.3 节的 `[方括号]` 项替换成你真实的精力节律。
- 对外招生/海报物料需过禁词自检（见 SKILL.md 第六节）。
